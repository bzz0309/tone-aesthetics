# Makaron 图片广告测试 03：涩谷穿梭男女角色

## 测试目标

- 在同一广告世界中分别生成一位女性与一位男性，不沿用此前人物身份。
- 验证 `taste.md + styling-library.md` 能否让不同性别拥有独立脸型、发型和造型，同时共享同一场景质感。
- 交付两张独立竖版图片，便于单独投放、筛选或后续作为视频角色锚点。

## 共同广告世界

- 场景：雨后蓝调时刻的涩谷主路口，真实城市人流与车流穿梭。
- 画面：竖版 4:5，人物在行进中被抓拍，背景具有方向明确的运动模糊。
- 质感：年轻时尚杂志街拍与商业广告之间，不做赛博朋克，不靠霓虹堆砌气氛。
- 行为逻辑：两人都是在城市中移动的年轻内容工作者，道具应被真实使用，而不是装饰性摆拍。

## 女生版

- 身份：全新 23 岁东亚女性，F02 中性先锋方向。
- 造型调用：WBASE03 + WST01。
- 造型信号：酒红色内层挑染、炭灰滚边短 T、黑灰宽松工装牛仔、半穿石板蓝外套、烟灰框眼镜、银黑运动鞋。
- 身份道具：有线耳机、银色小型摄像机、酒红色相机小包。
- 文件：`shibuya-female.png`

## 男生版

- 身份：全新 23–24 岁东亚男性，M04 都市利落为主，叠加少量 M05 年轻活力。
- 造型调用：MBASE03 + MST04。
- 造型信号：橄榄绿短夹克、深海军蓝针织 Polo、炭灰宽褶裤、窄矩形金属眼镜、银色头戴耳机。
- 身份道具：手机稳定器、黑色斜挎包。
- 文件：`shibuya-male.png`

## 年龄校准记录

- 男生第一版造型、动作与场景成立，但面部视觉年龄偏向 28–30 岁，未通过项目默认的 Z 世代年龄门槛。
- 最终版只调整面颊软组织、眼下状态、颊颌过渡、胡茬阴影与发丝空气感，保留原场景、动作、服装和道具。
- 第一版保留为 `shibuya-male-v1-mature-draft.png`，用于记录年龄门槛失败样本，不作为正式交付。

## 生成方式

- 使用 Codex 内置图片生成功能。
- 女生版为全新文生图；男生最终版以第一版为底图做身份保持式年龄校准。
