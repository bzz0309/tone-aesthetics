# STYLING LIBRARY / 品牌广告人物造型库

> 版本：v0.5  
> 适用：18–30 岁亚洲成年广告人物  
> 作用：根据人物性别、品牌调性、人设、动作和场景选择完整造型；不得用于重新设计人物骨相。

## 0. 库的边界

- `taste.md` 的 F01–F05、M01–M05 决定人物**长什么样**。
- 本造型库的 WST01–WST10、MST01–MST06 决定人物**以什么方式出现**。
- P01–P08 或自定义 Persona 决定人物**是谁、为什么这样穿、正在做什么**。
- 同一人物可以在不同广告中更换造型路线，但脸型、眼距、鼻唇、发际线、年龄和稳定识别点不变。
- 女性与男性使用两套独立造型分类，不把女装路线直接性别转换为男装路线。

## 1. 调用输入与输出

### 最少输入

```text
GENDER: WOMAN / MAN
BRAND CATEGORY: {时装、运动、科技、美妆、音乐、饮料、生活方式等}
BRAND TONE: {清冷、新潮、甜酷、智性、松弛、利落、活力等，最多3个}
PERSONA: {P01–P08或自定义}
ACTION: {角色正在完成的一个真实动作}
SCENE: {支持动作发生的空间}
```

### 标准输出

```text
STYLING ROUTE: {WST或MST编号}
BASE LOOK ID: {WBASE或MBASE编号；强概念造型可写DIRECT}
LOOK ID: {具体Look编号}
SILHOUETTE: {唯一主廓形}
GARMENTS: {外套、内搭、下装、鞋，按穿着顺序}
HAIR SHAPE: {发长、层次、刘海、束发与风动状态}
HAIR COLOR: {基础发色 + 最多一处受控染色}
MAKEUP / GROOMING: {唯一妆容或修饰重点}
PRIMARY STYLE SIGNAL: {一个最强识别信号}
ACCESSORY ZONES: {最多三个区域，每区一个主物件}
HERO PROP: {一个被真实使用的道具}
SUPPORT PROP: {可选一个空间证据道具}
COLOR SYSTEM: {基础色75% + 结构色15% + 一个强调色10%以内}
SCENE REASON: {人物为什么会以该造型出现在该场景}
```

## 1.1 Z 世代基础衣橱 / BASE WARDROBE

基础衣橱是可反复调用的商业化廓形骨架，不承担完整风格表达。常规品牌广告先选择一个 Base Look，再由 WST／MST 路线修改发色、妆容、材质、配饰和强调色；强概念时装、朋克、Ballet Edge 等可以直接调用路线内 Look，并将 `BASE LOOK ID` 写为 `DIRECT`。

### 女性基础衣橱 / WOMEN BASE

#### WBASE01 宽松牛仔套装 / RELAXED DENIM SET

- 短款或常规长度宽松牛仔夹克，开放穿着；内搭白色罗纹背心或短 T。
- 同洗色宽腿牛仔裤；黑色薄底训练鞋或扁平皮鞋。
- 适配：WST01、WST02、WST03、WST06；街头、音乐、生活方式与年轻时装。

#### WBASE02 Ringer Tee + 阔腿牛仔 / RINGER WIDE DENIM

- 合体滚边短 T，圆领、棉质、无第三方文字。
- 中低腰水洗阔腿牛仔；细腰带；薄底训练鞋。
- 适配：WST02、WST03、WST04；社交、手机、游戏、音乐与轻运动。

#### WBASE03 Baby Tee + 工装裤 / BABY CARGO

- 合体 Baby Tee 或短款罗纹上衣。
- 卡其、灰绿或冷灰宽松工装裤，口袋控制在 2–4 个；低帮板鞋。
- 适配：WST01、WST02、WST03；饮料、手机、城市出行与潮流服饰。

#### WBASE04 复古球衣 + 运动短裤 / RETRO JERSEY SHORT

- 无真实队标的复古球衣、短 Polo 或品牌自有运动短 T。
- 圆弧运动短裤；白色中筒袜与复古训练鞋。
- 适配：WST03，WST02 可提供不超过20%的色彩或银灰细节；时尚运动、耳机、饮料与社交内容。

#### WBASE05 半拉链卫衣 + 宽腿裤 / HALF-ZIP WIDE

- 旧化海军蓝、炭灰或奶白半拉链卫衣，内露少量白色下摆。
- 深水洗宽腿牛仔或干净阔腿训练裤；薄底鞋。
- 适配：WST03、WST06、WST01；城市日景、旅行、校园外生活方式与科技休闲。

#### WBASE06 短西装 + 合体内搭 / CROPPED BLAZER FITTED BASE

- 烟草棕、炭灰或黑色短西装，开放穿着；内搭合体无袖上衣或短 T。
- 深靛直筒牛仔或同色阔直长裤；乐福鞋或极简皮鞋。
- 适配：WST04、WST06，WST01 可提供一处金属细节；设计、眼镜、香氛、科技与编辑时装。

#### WBASE07 短 Polo + 百褶裙 / CROPPED POLO PLEATS

- 合体短 Polo 或小翻领针织，领口保持克制。
- 成年比例的百褶短裙叠安全裤；中筒袜与乐福鞋／训练鞋二选一。
- 适配：WST03、WST04、WST02；时尚运动、Hot Nerd、社交与年轻配饰。
- 禁止：真实校服、校徽、未成年姿态和性感校园 Cosplay。

男装基础衣橱保持四套，重点覆盖牛仔、城市休闲、运动与轻功能，不追求与女装数量对称。

#### MBASE03 半拉链卫衣 + 阔腿工装 / HALF-ZIP CARGO

- 适配：MST04、MST05、MST01；城市出行、运动科技、耳机、游戏与智能设备。

#### MBASE04 复古运动上衣 + 短裤／训练裤 / RETRO SPORT

## 2. 自动匹配规则

### 2.1 匹配顺序

1. 先确定 `GENDER`，只进入对应性别的造型池。
2. 常规商业主题先从对应性别的基础衣橱选择一个 Base Look；强概念主题可直接进入路线 Look。
3. 根据 `BRAND TONE` 与 `BRAND CATEGORY` 选择一条主造型路线。
4. 用 Persona、Action 和 Scene 在该路线中选择具体 Look，或用该路线覆盖 Base Look 的发色、妆容、材质、配饰与强调色。
5. 只允许一个主路线；确有复合调性时，次路线最多贡献 20% 的材质、颜色或一件配饰，不能贡献第二套完整廓形。
6. 补齐发色、妆容、配饰和道具后，再进入广告场景生成。

### 2.2 潮流发色主动路由

发色先读取人物身份路线，再读取造型路线和广告主题。主题只能在人物路线允许的色域中选择，不能越过身份气质强行漂染。

#### 女性身份路线色域

| 人物路线 | 默认发色范围 | 使用原则 |
|---|---|---|
| F01 清冷极简 | 自然黑、蓝黑、冷深棕 | 依靠发型几何、光泽和剪裁体现潮流；不默认漂浅 |
| F02 中性先锋 | 银灰、灰金、烟紫、冷蓝黑、双色内层、受控撞色 | 可把发色作为主识别信号，适合先锋、街头、音乐与建筑感画面 |
| F03 自然淡颜 | 自然黑、柔深棕、茶棕、日晒棕 | 保留原生、松弛与生活感；避免不自然高饱和色 |
| F04 摩登浓颜 | 亮泽黑、浓缩咖啡棕、深巧克力、低明度酒红棕 | 以浓郁深色衬托眉眼与唇部体量，不让发色抢夺五官 |
| F05 灵动甜酷 | 香槟浅金、铜橘、草莓棕、烟粉紫、彩色内层挑染 | 可主动变化显眼发色，保持轻盈、灵动和年轻感 |

时尚、街头、潮流、音乐、亚文化和年轻奢侈品主题优先在 F02、F05 中启用明显发色；选择 F01、F03、F04 时仍以其深色或自然色域为准。

- **冷调先锋：**冷香槟浅金、珍珠灰、烟紫、蓝黑或灰蓝内层；适配 WST01、WST07、WST08、MST04、MST06。
- **暖调复古：**茶棕、铜红、焦糖棕、酒红或日晒褪色金；适配 WST02、WST04、WST09、MST03、MST05。
- **朋克／亚文化：**漂浅沙金带自然深根、冷灰碎层、局部高对比挑染；适配 WST08、WST09、WST10、MST06。
- **清冷极简：**自然黑、深棕、蓝黑或低对比冷灰发片；不为了“潮”强行漂浅。

发色强度与其他信号做减法：整头浅色或强挑染已经占一个主信号时，眼妆、图形上衣、大首饰和复杂配饰最多再保留一个。发色必须与服装强调色或环境光产生一次呼应；身份锁建立后，A/B 图保持发际线、分缝、底色、挑染区域和长度一致。

### 2.3 评分

| 判断项 | 分值 |
|---|---:|
| 品牌调性命中 | +3 |
| 产品品类命中 | +3 |
| 人设命中 | +2 |
| 动作可由该造型完成 | +1 |
| 场景与材质、鞋履、道具合理 | +1 |

选最高分路线。并列时选择符号更少、产品露出更自然的一条；不得为了“更潮”选择元素更多的一条。

## 3. 女性造型池 / WOMEN

### WST01 新潮叛逆 / NEW-WAVE REBEL

- **关键词：**地下文化、实验音乐、DIY、非主流但高级、主动挑战规则。
- **适合：**潮牌、音乐、耳机、游戏、个性美妆、年轻饮料。
- **发妆：**黑色发根配漂浅金、冷灰或一处高对比发片；短层次、碎刘海或风动长直发；减淡眉色或细锐横向眼线二选一。
- **配饰：**耳圈／穿孔、头巾／针织帽、链条／皮带三个区域最多选二；发色强时金属必须减少。
- **场景：**后台、器材装卸区、排练室、地下展演空间、具有表演逻辑的开放场地。

#### W01A REBEL BACKSTAGE

- 旧化炭灰短版连帽卫衣或落肩图形 T，内搭纯色罗纹背心。
- 黑色直筒工装裤或水洗灰牛仔短裙叠安全裤；旧化训练鞋。
- 主信号：漂浅发片或一只结构耳饰。
- 道具：门禁卡、掌上摄影机、耳机、乐器线缆四选一并真实使用。

#### W01B MOTO LOADOUT

- 黑色短机车夹克或水洗牛仔／皮革短背心，搭奶白罗纹上衣。
- 低腰深靛宽腿牛仔或干净工装裤；厚底靴但不过度增高。
- 主信号：包覆墨镜、头巾、金属腰带三选一。
- 道具：头盔、工具包、乐器盒三选一；适合装卸、出发或到场动作。

### WST02 Y2K 甜酷 / Y2K SWEET-COOL

- **关键词：**明亮、镜头意识、甜与冷并存、社交传播、复古数码感。
- **适合：**彩妆、饰品、手机、社交应用、游戏、香氛、年轻时装。
- **发妆：**长直黑发、轻薄刘海、银灰／蓝灰脸侧发片；青蓝或粉紫眼妆只选一个主色，搭低饱和亮泽唇。
- **配饰：**发夹、窄墨镜、银饰、小肩包最多三个区域；蝴蝶、星星等符号只保留一个。
- **场景：**彩色棚、街机厅、镜面化妆空间、快闪店、便利店停车区。

#### W02A DENIM POP

- 奶白／黑色滚边 Baby Tee 或短款无袖运动上衣。
- 低腰水洗宽腿牛仔、牛仔短裙叠安全裤或干净运动短裤三选一；薄底训练鞋。
- 主信号：一处银灰发片或彩色眼妆。
- 道具：掌机、手机、迷你相机三选一。

#### W02B ARCADE SILVER

- 冷蓝、灰银或深靛合体短上衣，局部牛仔或铬银滚边。
- 深靛直筒牛仔或不对称短裙；黑色扁平鞋。
- 主信号：金属发夹或窄银框眼镜。
- 道具：游戏手柄、耳机、自拍相机三选一；动作必须具有反应感。

### WST03 韩系运动 / K-SPORTY

- **关键词：**清爽、利落、身体反应、时尚性高于专业竞技。
- **适合：**运动服、运动鞋、健康应用、手机、耳机、饮料、防晒、身体护理。

- **配饰：**头带、腕带、运动包、耳机最多两项。

- 主信号：海军蓝、奶白与运动红中的单一红色点缀。

- **关键词：**聪明、讲究、不经意吸引力、知识感与时装意识。

## 6. 组合禁令与 QC

- 不跨性别复制整套 Look；如需中性表达，只提取廓形或材质，不复制全部单品关系。
- 一套造型只能有一个主廓形、一个主造型信号和一个强调色。
- 发色、眼妆、眼镜、大首饰、图形上衣五种强信号中最多同时出现两个。
- “层构街头”至少保证 70% 面积属于同一主色系；“朋克／亚文化”至少保留一处干净留白，禁止靠元素数量制造风格。
- 短上装 + 超宽下装、短裙 + 重型靴、超宽外套 + 长内层三种比例只能选一种作为主廓形。
- 配饰最多覆盖三个区域；同一区域只保留一个主物件。
- 英雄道具必须服务 Persona 并被真实使用，不能为了“丰富画面”临时添加。
- 场景必须解释造型：鞋履适应地面，外套适应天气，包和道具适应动作。
- 不生成第三方 Logo、球队标识、校徽、杂志标题、乱码文字或可识别商品复刻。
- 不用幼态校服、性感秘书、健身网红、油腻商务、廉价朋克或全身流行符号堆叠替代真实风格。

### PASS

- 性别池、品牌调性、Persona、动作和场景之间没有冲突。
- 远看先读到廓形，近看才读到配饰和材质。
- 发型、发色、妆容、服装、配饰、道具构成一个角色，而不是六套趋势拼贴。
- 同一身份更换 Look 后仍能保持脸、年龄、发际线和身体比例。

### REROLL

- 造型路线正确但单品过多、强调色过多或道具没有动作关系。
- 男性和女性造型出现机械性互换，或所有人物被做成同一种 Y2K／朋克／极简模板。
- 服装适合棚拍但不适合指定场景、天气或动作。
