# Prompt Summary｜Identity vs Styling Separation

## 01 facial correction

身份保持式编辑，只调整眼睛以下的外轮廓：扩大中央与下部面颊、拓宽下颌、缩短下庭、去除下巴中央尖点，形成短宽浅U形圆钝下巴。眼、眉、鼻、唇、长发、服装、背景与光线全部锁定。

## Y2K styling module

以修正后的同一01身份为唯一底图。参考图只提供黑白撞色短上衣、早期运动时尚剪裁、粉调妆容、细猫眼线、刘海与金属发夹。禁止改变脸型、眼鼻唇比例与年龄；禁止复制参考人物、品牌字标与具体图案。

## Method

使用内置图像编辑能力。01经历一次初始编辑和一次定向重试；Y2K验证图为独立的一次身份保持式造型编辑。
