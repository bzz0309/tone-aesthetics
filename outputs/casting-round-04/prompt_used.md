# Prompt Set｜D2 Controlled Refinement

## Method

使用单一底图做身份保持式编辑；每个变体独立生成一次。原版 D2 是唯一人物参考，未混入其他模特脸。

## Locked invariants

- 同一位 22–27 岁东亚女性。
- 同一脸部骨架、眼距、鼻唇关系与发型长度。
- 正面胸像、灰色棚拍背景、黑色圆领上衣、柔和棚灯。
- 自然高级、非网红脸、无偶像妆、无尖下巴、无磨皮。

## V1 delta

- 眼裂纵向收窄约 8%，横向轻微延伸。
- 眉位略低并变得平直。
- 下颌线略直，下巴略宽、略钝。
- 降低唇部光泽，发尾更有束状层次。

## V2 delta

- 眉眼和嘴角加入 2–4% 的自然不对称。
- 弱化眼线，增加毛孔、细微肤色变化和面部绒毛。
- 表情更松弛，发丝和发尾减少沙龙式整齐感。
