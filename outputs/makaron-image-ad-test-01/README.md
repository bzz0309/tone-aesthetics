# Makaron 图片广告链路测试 01

## 测试目标

验证 `taste.md + styling-library.md` 能否在不复制真人的前提下，输出同一位 Z 世代亚洲人物的身份肖像和广告世界主视觉。本轮只测试静态图片，不生成视频。

## 自动匹配结果

- 品牌：Makaron AI 视频 App
- 角色：21 岁亚洲女性数字影像创作者
- 人物路线：F05 灵动甜酷
- 基础衣橱：WBASE03 Baby Tee + 工装裤
- 造型路线：WST01 新潮叛逆
- 身份识别点：短中庭、圆润脸颊、圆下巴、稍宽眼距、细长杏眼、黑色长直发与银灰脸侧发片、蓝灰横向眼线、单只银色耳骨夹

## 输出

- `makaron-creator-identity-a.png`：中性影棚身份肖像，用于判断脸、年龄和稳定识别点。
- `makaron-creator-ad-world-b.png`：同一人物的横版广告世界图；手机、微缩布景、摄影滑轨和 LED 生成世界共同表达“把一个简单想法变成电影画面”。
- `makaron-creator-home-music-b2.png`：按用户新要求生成的居家听音乐版。角色在年轻创作者公寓中戴银色头戴式耳机听音乐，手机的音乐转视频界面与墙面投影表达 Makaron 的产品关系。

## 生成方式

- 工具：Codex 内置图像生成。
- A 图为新建原创人物。
- B 图以 A 图为身份参考，强制保留脸型、眼距、鼻唇、发际线、发色分区、眼妆和耳饰。
- 广告世界提示核心：明亮虚拟制片棚，创作者用手机和微型摄影滑轨操作实体微缩布景，布景在 LED 墙上扩展为完整的天空与水面电影世界。

## 初步检查

- A 图年龄感、脸颊圆度、短中庭和圆下巴符合当前规则。
- B 图场景具有明确的 AI 视频制作因果，不是无关街头背景。
- B 图保留了主要身份识别点；是否进入下一轮仍以用户对脸、造型和品牌感的并排判断为准。
- B2 将基础衣橱改为 WBASE05 居家音乐变体：深海军蓝半拉链上衣、奶白滚边内搭、宽松深靛牛仔、银色耳机和铬色音箱。背景行为和道具均围绕“在家听音乐并生成音乐视觉”展开。
