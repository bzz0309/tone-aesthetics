# Makaron 居家听音乐人物测试 02

## 修正目标

上一轮把“换成在家听音乐”理解为同一人物换场景，因此继续使用了首位女生的身份锁。本轮重新建立一位完全不同的亚洲女性，只保留用户认可的穿搭、配饰和居家氛围。

## 人物与造型

- 人物路线：F03 自然淡颜。
- 年龄：22 岁亚洲女性视觉创作者。
- 结构差异：中等长度柔和椭圆脸、正常中庭、平均眼距、轻微下垂杏眼、自然偏宽圆鼻头、左侧下颊稳定小痣。
- 发型：暖深棕锁骨长度碎层次，自然弯曲。
- 基础衣橱：WBASE05 半拉链卫衣 + 宽腿裤的居家音乐变体。
- 造型保留：深海军蓝半拉链、奶白滚边内搭、宽松深靛牛仔、银色头戴耳机、银灰复古跑鞋和蓝色袜子。

## 输出

- `makaron-home-listener-identity-a.png`：新人物身份肖像。
- `makaron-home-listener-ad-world-b.png`：同一人物的居家听音乐 Makaron 广告世界图。

## 场景逻辑

人物在蓝色模块沙发上听音乐，手机呈现波形和视觉帧，墙面投影将音乐扩展为银色液态造型与珊瑚色日落影像。铬色音箱、黑胶唱片和暖色窗光共同证明“居家听音乐”，而不是任意室内背景。

## 生成方式

- 使用 Codex 内置图像生成。
- A 图不使用上一位人物的参考图，重新创建身份。
- B 图仅使用本轮 A 图作为身份参考，不调用旧人物。
