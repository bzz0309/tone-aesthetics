## 路由结论

- 街头时尚的核心不是“站在街上”，而是能够支持移动的比例、层搭和收纳系统。
- 亚文化的核心不是黑衣服，而是 DIY 痕迹、低保真媒介、收藏／试听／改造行为及匹配空间。
- 朋克的核心不是链条数量，而是锐利发型、低腰或重腰线、音乐语境和有秩序的金属系统。
- 简约中性的核心不是无妆基础款，而是克制色彩、清楚短上装结构与松弛长裤比例。
- 日系朋克男必须进入男性独立路线 MST06，不从女性 WST09 直接转换。
